# AsuransiJiwa

Proyek JSP Asuransi Jiwa.

## GitHub Pages Preview
File `index.html` ditambahkan khusus untuk preview statis GitHub Pages.

File asli tetap dipertahankan:
- JSP pages
- WEB-INF
- Java Servlet
- Database SQL
- Library MySQL Connector

Catatan: GitHub Pages tidak menjalankan JSP/Java Server. Untuk fungsi login, database, dan servlet gunakan Apache Tomcat/NetBeans.
